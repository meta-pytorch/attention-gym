# Tutorials

Practical, end-to-end guides for understanding and integrating Attention Gym features.
Tutorials complement the API-oriented pages by starting from a concrete problem, building a
working example, and explaining the relevant tradeoffs and failure modes.

New tutorials should keep executable code in `examples/` when practical so readers can run the
complete program from a repository checkout. See the
[documentation authoring guide](../developers/documentation.md) for supported diagrams,
annotations, tabs, source inclusion, and interactive widgets.
